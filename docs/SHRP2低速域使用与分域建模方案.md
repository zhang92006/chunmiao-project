# SHRP2 低速域使用与分域建模方案

## 结论

项目不限制为高速公路场景，因此可以使用低于 `20 m/s` 的 SHRP2 数据。之前的 `20–40 m/s` 范围只是当前 D2RL/NDD 模型的实验域，不是项目必须遵守的限制。

但是，低速数据不能直接混入当前高速 NDD 模型。当前模型在低于 `20 m/s` 时可能没有有效的动作概率分布 `p(a|s)`，此时 importance weight 中的 `p/q` 无法正确计算。

## 当前低速数据的价值

在此前 1484 个候选种子中，至少约 1368 个因为车辆速度低于当前 D2RL 下限而被桥接器阻断。这部分数据具有较大的回收价值，但不能只把配置中的最低速度从 20 改成 0。

低速数据可能包含：

- 城市道路跟车；
- 路口接近和排队；
- 低速换道；
- 拥堵和 stop-and-go；
- 低速追尾与侧向冲突。

这些场景有助于扩展多智能体 D2RL 的适用范围，但需要匹配的行为模型和道路拓扑。

## 建议的速度分域

| 速度域 | 建议处理 |
|---|---|
| `20–40 m/s` | 保留当前高速 NDD/D2RL 模型 |
| `5–20 m/s` | 建立低速行为模型或低速 NDD 分布 |
| 接近停车、排队 | 单独建立 stop-and-go 模型 |
| `>40 m/s` | 作为异常或少量高速样本单独审查 |

这里的速度边界只是初步分域，最终下限应根据低速数据和动作概率模型的实际支持范围确定，不能直接假设 `0–40 m/s` 全部有效。

## 为什么不能直接放宽速度范围

当前 D2RL 使用行为动作概率分布。对于低速状态，如果 NDD 模型没有该状态的有效概率：

1. `p(a|s)` 可能为零或没有定义；
2. importance weight `p/q` 失去统计意义；
3. 低速样本会被错误地解释为高速驾驶行为；
4. 训练出来的策略可能在低速场景中产生不合理加速度和换道动作。

因此，直接修改桥接器阈值只能增加文件数量，不能保证增加有效训练数据。

## 推荐模型结构

### 方案一：共享编码器加分域行为模型

```text
场景状态
   ↓
共享状态编码器
   ├── 高速行为模型 p_high(a|s)
   ├── 低速行为模型 p_low(a|s)
   └── 停车/排队模型 p_stop(a|s)
```

这是最容易验证的方案。不同速度域使用各自的动作概率分布和 proposal 分布，同时保留统一的多智能体接口。

### 方案二：统一条件模型

```text
p(a | 状态, 速度域, 场景拓扑)
```

该模型可以共享更多数据，但需要更多训练样本和更严格的分域消融，适合作为后续扩展。

当前建议先实现方案一，再考虑统一条件模型或条件扩散模型。

## Importance weight 要求

高速和低速域必须分别计算：

```text
p_high / q_high
p_low  / q_low
p_stop / q_stop
```

不能用高速 NDD 概率去计算低速样本的权重。每个样本还应增加：

- `domain_id`：高速、低速或停车；
- `behavior_model_version`；
- `proposal_model_version`；
- `log_naturalistic_probability`；
- `log_proposal_probability`。

训练时应按速度域分层采样，并分别报告每个域的碰撞率、轨迹误差和有效样本量。

## 拓扑要求

低速域往往对应城市道路、路口、排队和行人场景。因此，扩展速度域的同时需要扩展 SUMO 拓扑：

| 场景类型 | 推荐拓扑 |
|---|---|
| 低速跟车、低速追尾 | 两车道或三车道直路 |
| 低速换道、并线 | 三车道道路 |
| 路口接近和转弯 | 四岔路口或信号交叉口 |
| 行人冲突 | 城市道路和人行横道 |
| 停放车辆遮挡 | 城市道路路侧停车拓扑 |

如果只扩大速度范围、仍使用两车道直路，样本数量会增加，但转弯、横穿和行人冲突仍无法正确映射。

## 下一步实施顺序

1. 对被速度筛掉的 SHRP2 样本建立速度、加速度、间距和冲突类型分布统计；
2. 检查低速样本是否具有足够的动作观测；
3. 建立低速行为模型，并验证低速状态下动作概率是否完整；
4. 在桥接模板中加入 `domain_id` 和行为模型版本；
5. 先用低速两车道/三车道场景验证接口；
6. 再扩展到路口、行人和停车场景；
7. 分别评估高速域、低速域和跨域训练效果。

## 对项目范围的影响

项目可以从：

```text
高速公路多智能体碰撞生成
```

扩展为：

```text
跨速度域、跨拓扑的多智能体危险场景生成
```

但论文中必须明确报告不同速度域和拓扑的结果，不能把所有样本混合后只给出一个总体碰撞率。
