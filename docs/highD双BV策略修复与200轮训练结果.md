# highD 双 BV：策略输出修复与 200 轮训练结果

实验日期：2026-09-26。按用户要求，先修复已确认的策略输出缺陷，再从固定基线初始化重新训练 200 轮。本轮已实际运行完成，不是待执行方案。

## 1. 结论

**输出范围和初始化问题已修复；200 轮训练正常完成，但没有稳定超过固定 epsilon=(0.1,0.1)。**

最终训练池经验二阶矩为 0.0626882，旧版 80 轮为 0.0741944，固定基线为 0.0626204。新结果比旧版低约 15.51%，但仍比固定基线高 0.108%，基本持平。

尤其要区分：新策略从固定基线起步，训练前已经是 0.0626204。因此，相比旧版的改善不能全部归功于 PPO 学到了更好的策略；本轮更明确地证明了接口修复有效，而不是证明了 200 轮学习带来了稳定收益。

## 2. 本次修改了什么

1. 新增可选的 `highd_mean_precision_beta_v1`，直接参数化 Beta 均值和集中程度。旧 Ray 分布及既有 checkpoint 保留，不修改安装环境。
2. 使用独立的策略网络初始化：两个确定性 epsilon 均为 0.1，初始 Beta 集中程度为 80。隐藏层仍为 64×64，价值网络保留普通初始化。
3. 初始化核验覆盖训练池全部 1,368 个关键状态：epsilon 最大误差为 7.45×10⁻⁹，训练前经验目标与固定基线一致。
4. 训练记录增加策略版本、代码校验值、初始化结果、policy loss、value loss、entropy 和 KL；诊断入口可恢复新旧两种策略。

新分布使用有界均值与正集中程度，并使两个 Beta 形状参数不小于 2，避免边界奇异密度。归一化动作的对数密度和熵包含从 [0,1] 到 [-1,1] 的缩放项；未裁剪抽样动作或重要性权重。

为浮点稳定性，确定性 epsilon 均值范围约为 [0.050095,0.999905]，不是声称能精确取到 0.05 和 1 两个端点。它已能准确表示 0.1，也能表示旧版无法达到的更低均值。

两个 Beta 变量用于两个干预强度的探索，并不意味着两辆 BV 的自然动作相互独立；BV 动作仍使用原来的条件联合 P/Q。训练前的确定性均值与固定策略相同，但随机探索分布不是一个固定常数策略。

## 3. 保持不变的条件

- 冻结 NDD、双车道、CAV 和执行器；8 项冻结校验全部一致。
- 同一 80 条行为 episode，42 条非空关键序列；保留全部 80 次分母。
- 事件仍为 8 秒内首次碰撞时刻涉及 CAV。BV-only 是竞争终点，不是完整时域安全样本。
- 条件联合 P/Q、完整序列重要性权重、二阶矩奖励及固定正缩放不变；非空抽样修正为 42/80。
- seed=7，学习率 0.0003，batch 512，minibatch 128，每批 5 次 SGD，gamma=lambda=1。

这不是在旧 80 轮模型上续训，而是修复后重新训练 200 轮，累计 121,558 次回放交互。回放次数增加不等于新增独立仿真轨迹。本轮没有新增 SUMO 闭环实验。

## 4. 训练结果与曲线

指标为同一训练池上的归一化经验路径二阶矩，越低越好；不是碰撞率、NLL 或测试集统计效率。

| 对照 / 训练位置 | 经验二阶矩 |
|---|---:|
| 固定 (0.1,0.1) | 0.0626204 |
| 旧版 80 轮 | 0.0741944 |
| 新版训练前 | 0.0626204 |
| 新版 20 轮 | 0.0620116 |
| 新版 40 轮 | 0.0610174 |
| 新版 55 轮，已记录指标最低点 | 0.0608171 |
| 新版 80 轮 | 0.0621708 |
| 新版 120 轮 | 0.0616848 |
| 新版 160 轮 | 0.0622496 |
| 新版 200 轮，实际保存模型 | 0.0626882 |

第 55 轮比固定基线低约 2.88%，但最终比这个已记录最低点高约 3.08%。最后 50 轮的十个评估点介于 0.0622052–0.0632663，200 轮比 150 轮高约 0.92%。

所以应描述为“围绕基线波动、早期改善后回退”，不能说已经收敛到稳定优于基线的解。只有一个训练随机种子，且没有预设收敛判据或独立验证结果，也不能将 0.108% 的差距解释为显著优劣。

本轮每 5 轮记录指标，但仅保存最终 checkpoint；第 55 轮只有指标，没有可直接恢复的 checkpoint。不能宣称已经选择或部署了第 55 轮模型。

## 5. 保存模型的复核

恢复第 200 轮 checkpoint 后，重新计算得到 0.06268816573932413，与训练结束记录 0.06268816573932408 一致。训练数据、训练环境、事件定义、策略实现和训练入口的校验值也与本轮记录一致。

| 全部关键状态上的输出 | 第一个 epsilon | 第二个 epsilon |
|---|---:|---:|
| 最小 | 0.09757 | 0.11317 |
| 平均 | 0.10281 | 0.13195 |
| 最大 | 0.10478 | 0.19095 |

第一个 epsilon 已实际低于旧版均值下限 0.1101，确认新参数化生效。当前输出没有卡在新的数值边界。

训练池常数网格中，(0.05,0.05) 得到 0.0594568；接近新均值下界的常数也得到约 0.0594625。它们仍优于最终网络，说明当前优化尚未充分利用简单可行解。这个网格只是训练池诊断，未自动部署，也不是泛化证据。

## 6. 下一步

不继续盲目增加轮数，也不重新拟合 NDD。固定 (0.1,0.1) 继续作为主对照，新 checkpoint 暂作候选而非“性能更好的正式策略”。

优先处理 PPO 学习改善难以保留的问题：核对主导二阶矩的少数路径在批次中的优势信号、价值估计和更新贡献，同时区分随机探索奖励与确定性策略目标。已有数据中，后车接近占大量关键状态，但六条相邻车道碰撞路径主导目标；它可能增加学习方差，尚不能直接认定为全部原因。

若后续采用整序列分层抽样，必须保留对应抽样修正，不把所有碰撞奖励改成相同值。后续训练应保存中间 checkpoint，并将训练最低点与独立验证选模区分。再将预先固定的候选和常数基线放到同一自然目标的新随机种子闭环下比较。

本次没有实施上述后续调整，也没有自动扩大训练或接入闭环。
