# SHRP2 五来源 Seed19 训练与验证结果

## 本轮结论（2026-09-19）

20 轮 PPO 已正常完成，checkpoint-20 已保存。模型能优化训练池上的目标，
但本轮独立源事件验证低于固定 epsilon 基线，暂不扩跑多随机种子。

配置：`d2rl_training/d2rl_train_shrp2_multibv_frozen5_source_balanced_seed19.yaml`。
Ray trial：`PPO_shrp2_multibv_smoke_619de_00000_0_2026-09-19_15-47-38`。
训练池：`shrp2_multibv_frozen5_source_balanced_train_v1`，86 条 crash、5 个源事件。
验证池：`shrp2_multibv_validation14_x50_factorized_epsilon0001`，38 条 crash、3 个源事件。
已逐条核对，两组源事件无交集。训练使用 uniform_source，评估逐条等权、explore=False。

## 实测结果

训练累计 80,000 步，用时约 484.47 秒；平均 reward 从 -15.84 提升到 55.97。
value loss 从 6506.97 降到 899.02，解释方差从 0.058 升到 0.538。
最后五轮平均奖励在 54.53～55.97 之间，仍有 -100 样本；不能据此宣称充分收敛。

| 确定性离线评估 | 训练池 | 验证池 |
|---|---:|---:|
| 成功评估 / 总样本 | 86/86 | 38/38 |
| 独立源事件数 | 5 | 3 |
| 策略平均奖励（逐条等权） | 55.04 | -68.94 |
| 策略平均奖励（先按事件求均值，再等权） | 58.59 | -42.89 |

边界诊断定义为 epsilon < 0.002 或 > 0.998。后续审计已经确认：RLlib 默认对动作做
归一化，旧 checkpoint 的高斯策略原始动作经常落在 [-1,1] 之外，随后被映射并裁剪到
环境的 epsilon 边界。训练池 49/86、验证池 35/38 至少有一个原始动作越界；验证集
agent 0 的原始动作均值为 -2.733。这不是简单的显示问题，而是错误奖励产生的策略退化。

固定基线使用与策略完全相同的单个关键时刻。当前关键时刻本来就按参考 epsilon=0.5
下的可训练性筛选，因此基线没有 -100 截断包含选择规则的影响；需要明确报告这一点。

验证分源结果：

| 源事件 | 样本数 | 策略奖励均值 | 固定基线均值 | -100 数量 |
|---|---:|---:|---:|---:|
| 137038878 | 32 | -69.50 | 14.53 | 25 |
| 138077442 | 1 | 24.99 | -47.07 | 0 |
| 138608096 | 5 | -84.17 | 12.20 | 4 |

38 条中的 32 条来自同一个事件，独立验证证据仍然有限。两个主要验证事件上的表现
明显下降；目前证据支持“事件间迁移不佳、动作边界输出频繁”，尚不能把根因完全归于
过拟合、数据量或某个模型组件。

本评估读取已经发生碰撞的固定日志，重算策略 epsilon 对应的离线奖励；它没有重新
运行策略控制下的 SUMO，所以这些奖励和样本数量都不是学习后策略的碰撞发生率。

## 奖励契约审计与受控修正

实际逐车防御混合提议分布为：

`q(epsilon) = epsilon * p + (1 - epsilon) * c`

其中 `p` 是自然驾驶动作概率，`c` 是碰撞生成器/关键动作提议概率。每车的重要性权重
应为 `p / q(epsilon)`，联合权重为各受控 BV 权重之积。旧训练奖励却按权重大于或小于 1
使用 `1/epsilon` 或 `p/(1-epsilon)` 两个近似分支；一般 factorized 分布不满足该近似，
冻结 CEM 的 categorical proposal 更不满足。因此旧 checkpoint 优化的是错误代理目标，
其验证退化不能直接用于否定多智能体 D2RL 或碰撞生成器。

已完成两项修正：

1. 根据生成日志中的自然概率、生成权重和生成 epsilon 重建 `c`，再按新 epsilon 精确计算
   `p/q`；同时按 BV ID 对齐每车 epsilon，避免关键性顺序和受控车辆顺序不一致。
2. 将旧线性奖励的硬截断改为有界对数权重：
   `reward = -R * tanh(log(weight) / scale)`。当前 `R=100`、`scale=5`，保持单调性并避免
   大量样本直接饱和在 -100。

2 轮、8000 步短冒烟已经通过。第二轮训练平均 reward 为 16.27，最小值 -99.21；
value loss 约 1723，低于精确权重配旧线性奖励的约 4519。独立验证 38/38 可评估，
没有动作原始值越界、没有环境动作贴边，策略逐条平均 reward 为 1.78，固定
epsilon=[0.5,0.5] 在相同新奖励下为 1.32；策略在 29/38 条上更优。该结果只证明链路和
优化方向有效，2 轮不足以作为最终性能结论。

`data_analysis/raw_data/shrp2_multibv_exact_log_smoke_evaluation_v1/validation.json`。

## 精确对数奖励 20 轮结果与动作分布修正

精确混合权重配有界对数奖励的 Seed19 正式训练已完成 20 轮、80,000 步。训练时平均
reward 从 14.17 上升到 21.46，checkpoint-20 正常保存。确定性离线评估结果如下：

| 指标 | 训练池 | 独立验证池 |
|---|---:|---:|
| 成功评估 | 86/86 | 38/38 |
| 策略 reward 均值 | 24.52 | 1.88 |
| 固定 epsilon=[0.5,0.5] 均值 | 18.32 | 1.32 |
| 策略相对固定基线均值差 | +6.20 | +0.56 |
| 胜 / 平 / 负 | 61 / 12 / 13 | 29 / 0 / 9 |
| 至少一个动作被裁到边界 | 31/86 | 38/38 |

奖励修正消除了旧实验中大量 -100 硬饱和，但训练 20 轮后无界对角高斯仍在独立验证上
退化成“第一辆 BV 接近 0、第二辆接近 1”；验证 38/38 均发生边界裁剪。因此整体均值
略优不足以支持扩跑三 seed，且验证均值受仅有 1 条样本的事件 138077442 高奖励影响。

为隔离动作分布问题，新增在 RLlib 归一化空间 [-1,1] 上定义的独立 Beta 分布；它保留
PPO 所需的 log-probability、entropy 和 KL，并映射到 epsilon [0.001,0.999]。2 轮受控
冒烟结果为：验证 reward 1.44，固定基线 1.32，29 胜、9 负；原始动作越界 0/38，
环境边界动作 0/38。验证 epsilon 均值分别为 0.495 和 0.582。由此可见有界分布在不丢失
初步性能的情况下解决了裁剪退化。

有界 Beta 的 Seed19 正式训练也已完成 20 轮、80,000 步，训练 reward 从 16.96 上升到
21.51，最后 10 轮位于 21.31～22.88。最终 checkpoint 的确定性评估为：

| 指标 | 训练池 | 独立验证池 |
|---|---:|---:|
| 策略 reward 均值 | 24.95 | 1.84 |
| 固定 epsilon=[0.5,0.5] 均值 | 18.32 | 1.32 |
| 策略相对固定基线均值差 | +6.63 | +0.52 |
| 胜 / 平 / 负 | 59 / 12 / 15 | 29 / 0 / 9 |
| 按源事件等权的策略均值 | 22.55 | 24.28 |
| 按源事件等权的固定基线均值 | 18.56 | 22.27 |
| 原始动作越界 / 环境动作贴边 | 0 / 0 | 0 / 0 |

验证三个源事件中，策略相对固定基线分别为 +0.479、+5.807、-0.273；不是所有事件都
改善，但两个事件改善且总体 29/38 逐条改善。无界高斯的验证均值 1.88 略高于 Beta 的
1.84，但差值仅 0.04，且前者 38/38 被裁到动作边界。因而有界 Beta 是更可信的正式
候选。当前证据满足进入多随机种子复现的预设门槛，但验证只有 3 个独立源事件，不能据此
宣称广泛泛化。

对应文件：

- 无界高斯正式评估：`shrp2_multibv_frozen5_exact_log_seed19_evaluation_v1`
- 有界 Beta 冒烟评估：`shrp2_multibv_bounded_beta_smoke_evaluation_v1`
- 有界 Beta 正式评估：`shrp2_multibv_frozen5_bounded_beta_seed19_evaluation_v1`

## 下一步顺序

1. 固定有界 Beta、精确混合权重、有界对数奖励和全部数据协议，再补跑 seed 7、29，
   与现有 seed 19 组成三随机种子；不能根据验证事件分别调参。
2. 每个 seed 锁定 checkpoint-20，在同一 86 条训练和 38 条验证 crash 上确定性评估，
   报告逐条均值、按事件等权均值、相对固定基线差值及动作边界诊断。
3. 三 seed 均无边界退化且验证相对基线方向稳定后，再接入闭环 SUMO，报告碰撞覆盖、
   有效样本数、重要性权重和采样效率；若 seed 间方向不稳定，优先扩大独立训练源事件，
   而不是继续增加现有 5 个事件的重复 rollout。
   test 在模型开发期间继续锁定。
