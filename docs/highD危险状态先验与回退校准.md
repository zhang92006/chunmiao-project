# highD 危险状态先验与回退校准

后续真实运动与几何口径检查见
[highD换道纵向运动与回退几何审计.md](highD换道纵向运动与回退几何审计.md)。

## 当前结论

保留车距的纵向先验通过了本轮 calibration 筛选，但只改善了已覆盖状态的
单步动作分布。稀疏分箱硬回退和换道执行期间不能制动的问题仍未解决。
候选没有替换正式 NDD、没有改变 D2RL 33 动作接口，也没有进入训练数据池。

## 已执行改动

旧先验的层级是：全局 → 速度 → 相对速度与速度 → 完整跟车状态。
在细分箱观测很少时，车距被父层合并，可能把较大车距的动作概率用于小车距状态。

新候选层级是：全局 → 相对速度 → 车距与相对速度 → 完整跟车状态。
细层仍保留车距、相对速度和速度；所有先验只来自原 train 计数。父层强度仍为
100，细层候选强度沿用 1、10、30、100、1000。自由流表、横向模型、道路约束、
空分箱回退和动作空间均未修改。不存在根据验证碰撞强行增大制动概率的操作。

实现为 `highd_longitudinal_tail_calibration.py`，配置为
`configs/highd_longitudinal_tail_calibration_v1.json`。部分 recording 扫描只作
诊断，不选模型、不导出候选。完整扫描也只作 calibration 筛选，不自动部署。

## 数据和筛选协议

固定 train：01、02、04、05、07、08、11、12、15、16；计数来自已冻结模型。
实际读取 calibration：03、06、09、13、17、25、26、27、28、29。
本轮没有读取 validation/test 的真实轨迹用于拟合或选参。

25 Hz 源数据按原规则采样到平均 10 Hz，动作网格和支持域不变。危险子集使用
原始连续观测的 0 < TTC < 3 秒，而不是分箱中心估算 TTC。评分仍限于非空训练
分箱，空分箱不被伪装成 highD 已覆盖样本。

筛选要求总体与危险子集的 NLL、Brier 均不劣于基线，再在通过者中选总体 NLL
最小者。危险子集至少覆盖 100 帧、3 个 recording 才允许筛选；这些只是最低
诊断门槛，不是独立样本量要求或统计显著性证明。

## 完整 calibration 结果

共有 2,410,186 个合格帧，当前运行时支持域覆盖 2,381,075 帧，约 98.79%。
危险子集共 610 帧，覆盖 316 帧，只有 51.80%。10 个 calibration recording
均有已覆盖危险帧。候选强度 1000 通过筛选，100 虽然危险子集 NLL 略好，但
总体 NLL/Brier 变差，因此未选。

| 指标（越低越好） | 已冻结 v2 | 保留车距候选，强度 1000 |
|---|---:|---:|
| 总体已覆盖 NLL | 1.640403 | 1.628356 |
| 总体已覆盖 Brier | 0.733017 | 0.730446 |
| 危险子集已覆盖 NLL | 3.042308 | 2.590724 |
| 危险子集已覆盖 Brier | 0.945531 | 0.907527 |

这些是用于筛选的 calibration 分数，不是未见测试提升；危险帧有时间相关性，
不能把 316 帧当成 316 个独立危险事件。评分对象是条件纵向动作分布，不是完整
双 BV 联合分布，也不衡量闭环碰撞概率或 D2RL 统计效率。

## 回退审计暴露的不足

| 危险帧所在分箱的训练支持量 | calibration 危险帧数 |
|---|---:|
| 0，运行时回退 | 294 |
| 1–2 | 174 |
| 3–9 | 134 |
| 10–99 | 8 |
| 至少 100 | 0 |

总体覆盖高掩盖了危险状态覆盖不足。610 帧中，602 帧所在分箱不足 10 个训练
观测；仅改善非空分箱的父层先验，不能消除“空分箱用原模型，1 个样本就切到
highD”的边界突变。更不能据此宣称已经建立了可靠的危险状态自然驾驶分布。

## 候选运行短测

在 calibration 选定候选后，使用上轮 3 个已知失败回归模板和原种子做 8 秒
延长诊断。它们是已看过的开发回归，不是选参集，也不是独立泛化测试。
由于本轮更换模型，不能要求前 4 秒日志与旧模型相同；仍要求新模型概率重建正确。

| 原 episode / seed | 新候选结果 |
|---|---|
| 168 / 175 | 完成 8 秒，无碰撞 |
| 225 / 232 | SUMO 4.80 秒步内碰撞，runner 4.9 秒终止 |
| 285 / 292 | SUMO 4.80 秒步内碰撞，runner 4.9 秒终止 |

3/3 概率审计通过，合计 1,784 个动作决策。仍有 2 次 BV–BV 碰撞，不能以
比旧候选晚碰撞作为自然驾驶质量提升证据。换道期间固定 1 秒零加速度的结构
未改变，单独改纵向先验不能解决整个问题。

## 可复现结果与后续

完整结果位于 `highd_longitudinal_tail_calibration_v1/tail_calibration_summary.json`；
候选文件为同目录 `highd_longitudinal_gap_candidate.npz`，SHA-256：

`fb46d7c72ecd6424558bd4a80065305553e408939d10937455f9dce5119c16d1`

短测位于 `highd_gap_prior_horizon_regression_v1`，每个 episode 保存模型哈希、
种子、诊断标记、执行概率和重建审计。本轮 53 项 highD 相关测试通过。

下一步先保留这版为候选，不扩大 300 次仿真：

1. 审计真实 train/calibration 换道前后纵向减速，区分数据支持不足与固定执行
   语义不匹配，避免把真实需要换道同时制动的行为拟合成“禁止换道”。
2. 对空分箱及 1–9 样本分箱设计支持量感知的连续回退候选；评分必须覆盖这些
   原来被排除的状态，同时记录采用原 NDD 成分的比例，不能声称变成纯 highD。
3. 候选冻结后，再做闭环开发回归与独立评估。若修改换道纵向执行语义，需要
   同步核对自然概率、提议概率和双 BV 联合重要性权重，不能只改实际执行动作。

文档不包含运行命令。本轮离线校准和短测已由助手完成，无需重复运行。
