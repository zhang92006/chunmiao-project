# D2RL 双车道高速公路加速安全测试：过程与结果汇总

记录日期：2026 年 10 月 15 日。本文时间均为北京时间（UTC+8）。

**本次已完成原作者发布模型的 200,010 次双车道高速公路加速安全测试。10 个工作进程全部跑满，执行错误为 0，总耗时约 5 小时 17 分钟。重要性加权碰撞概率估计为 `1.224518 × 10⁻⁷`，90% 相对置信半宽（RHW）为 `20.81%`。**

本次任务完成了运行环境适配、概率表低内存加载、短跑验证及完整批次执行。没有重新训练模型，也没有使用此前自行拟合的 highD/V46 双车联合 NDE。

## 1. 任务与实验范围

任务是使用原作者已训练并发布的 D2RL 模型，对双车道高速公路中的自动驾驶车辆开展加速安全测试，保持提供的脚本预算：

```text
10 个工作进程 × 每进程 20,001 次 = 200,010 次测试
```

采用发布版本的单 POV/BV 干预方案，`dual_bv=off`。这里的“双车道”指道路有两条车道，不代表采用“双 BV 联合干预”。被测 CAV 使用发布版本的 IDM/MOBIL 控制器，包含其换道行为；不能将本次结果混同于此前固定车道 IDM CAV 上的 highD/V46 实验。

每次测试的统计单位是一个最长行驶 400 m 的 CAV 测试场景，发生 CAV 碰撞等终止条件时提前结束。下文的碰撞概率是**每次 400 m 测试的概率**，不是每公里事故率。

## 3. 内存问题及修复

原加载方式将三个大型稀疏换道概率表转换为完整稠密数组，合计约 **4.56 GiB/进程**。此前单进程实测 RSS 约 **4.70 GiB**；在约 16 GB 内存机器上直接复制十份不可行。

修复采用以下方式：

1. 保留原始 `float64` 概率值，将非零坐标转换为排序后的索引。
2. 启动前一次性生成缓存，工作进程以只读内存映射方式访问同一组文件。
3. 保持未存储位置的概率为零，并保留小型 OL 表所需的稠密、可迭代接口。
4. 使用有上限的查询缓存减少重复搜索；不重新拟合概率，不降为 `float32`。

四张表的缓存合计 **154.12 MB**（十进制）；其中三张大型表合计 **153.46 MB**。这是缓存文件大小，不应直接当作整个进程的内存占用。

| 测量阶段 | 单进程最大 RSS | 单进程最大私有内存 |
|---|---:|---:|
| 修复前的独立测量 | 约 4.70 GiB | 未作为本次证据记录 |
| 100 次短跑 | 257.14 MiB | 181.83 MiB |
| 本次 200,010 次全量 | 372.36 MiB | 217.23 MiB |

短跑时最初的外部监测只统计了 Windows 虚拟环境启动器，漏掉实际 Python 子进程。该短跑的进程组汇总值已排除，单进程内部记录仍有效；全量运行前已修复为统计整个进程树。

全量运行的内存结果：

| 指标 | 实测值 |
|---|---:|
| 十进程及其子进程私有内存合计峰值 | 2,192.91 MiB，约 **2.14 GiB** |
| 十进程及其子进程 RSS 合计峰值 | 3,819.28 MiB，约 **3.73 GiB** |
| 启动时系统可用内存 | 3.16 GiB |
| 运行中系统最低可用内存 | 1.94 GiB |

RSS 合计可能重复计算多个进程共享的页面，因此不等于它们新增占用的独立物理内存。上述峰值来自定期采样，单进程峰值来自进程内记录；不是连续捕获每一个瞬时峰值。本次全量运行没有出现内存中断，但单次完成不等于已证明任意更长运行都不存在内存增长。

## 4. 启动流程和必要验证

为保证固定预算能够审计，启动入口补充了以下行为：

- 显式指定每进程测试次数及随机种子；NumPy、Python 和 SUMO 使用对应场景种子。
- 每批创建新的时间戳目录，保留已有结果。
- 权重每 50 次保存，并在正常结束或捕获异常退出时最终保存。
- 记录请求数、尝试数、完成数、错误、模型调用次数、内存和模型哈希。
- 任一工作进程失败或结果数量不足时，不生成“完整批次成功”的汇总。
- PowerShell 入口默认只准备，只有加 `-Run` 才实际运行。
- 十进程启动前要求至少 3.00 GiB 可用内存。

准备阶段通过 `pip check`、4 项原始概率查询一致性检查及 4 项 SUMO 加减速执行检查，共 **8 项针对性检查通过**。

## 7. 指标解释与结论边界

### 7.1 两个碰撞指标的区别

**加速测试碰撞占比**为：

```text
581 / 200010 = 0.002904854757 = 0.290485%
```

它描述 D2RL 加速采样下碰撞事件出现的频率。由于场景采样被有意偏向危险事件，该值不能作为自然驾驶环境中的碰撞概率。

**重要性加权碰撞概率估计**使用每个场景的最终权重。令 `Y_i = I(C_i) × L_i`，其中 `I(C_i)` 表示是否发生 CAV 碰撞，`L_i` 为作者实现累计的场景重要性权重，则：

```text
p_hat = (Σ Y_i) / N
      = 0.024491587683787806 / 200010
      = 1.2245181582814761e-7
```

这对应当前固定 NDE、被测 AV 和 400 m 测试协议下的自然碰撞概率估计；不是直接针对真实道路总体事故率的测量。

### 7.2 置信区间及 RHW

汇总脚本对 `Y_i` 使用样本标准差 `s` 和 90% 双侧正态近似：

```text
半宽 = 1.64485362695 × s / sqrt(N)
RHW  = 半宽 / p_hat
CI90 = [p_hat - 半宽, p_hat + 半宽]
```

本次 RHW 为 **20.81%**，低于此前讨论的 **30%** 精度阈值。它是这批固定预算结果的事后统计量；固定跑 200,010 次并不预先保证达到该阈值，正态近似区间也不等于已经验证其有限样本覆盖率。

### 7.3 当前可以确认的结论

- 作者发布模型在本机双车道环境中完成了完整预算的加速安全测试。
- 低内存概率表加载方案支持了本次十进程完整运行，未修改原概率数值。
- 结果数量、权重、模型调用和碰撞日志相互一致；本次加权估计与 RHW 已可复查。

本次没有运行同预算的独立 NDE 对照，也没有运行双 BV 联合干预对照。因此不能据此给出实测加速倍数、单/双 BV 优劣或 D2RL 训练效率结论。本文也没有完成与论文结果的正式统计一致性检验；“完整执行发布模型协议”与“论文所有数值已复现一致”应分别表述。

报告中的 0 错误指没有记录到导致场景执行失败的异常，不代表 SUMO 日志没有任何提示；日志存在初始化车速因子调整警告。581 次碰撞是加速安全测试产生并计权的事件，不应当作脚本错误。
