# Scenario reconstruction：论文差距与实施路线

更新日期：2026-09-12。本文区分代码已经具备的能力、待验证的研究假设和未来实验，不把工程跑通写成论文效果。实施进展及实测数字另见 `实施记录.md`。

## 1. 当前判断

项目已经具备模板、参数扰动、Autoware 日志摘要、SUMO/NADE 运行和数据导出链路，但还不是经过真实轨迹验证的事故重建方法。建议先把研究问题收敛为：**在观测不完整时，如何重建与证据一致的交互轨迹，并量化局部扰动导致风险的边界及其不确定性？**

必须分开三项任务：

1. 重建：拟合真实观测并恢复被遮挡的轨迹；碰撞越多并不意味着重建越好。
2. 反事实生成：在重建基础上改变有限的可控量，寻找危险但物理合理的情形；记录改变了什么、改了多少。
3. 规划器测试：检查不同规划器在这些场景中的表现；仿真碰撞比例不是现实道路事故概率。

### 已发现的主要问题

| 问题 | 代码或实验依据 | 对论文的影响 |
| --- | --- | --- |
| 缺少完整、同步的真实轨迹真值 | `autoware_cdr.py` 主要输出少量样本和统计摘要；规划轨迹不等于实际行驶轨迹 | 无法证明重建准确，需处理坐标系、时间同步、对象关联和缺失值 |
| 示例碰撞不是原始事故复现 | 手写高速模板可以碰撞；已有 Qwen 原始状态模板测试 24 次运行没有训练就绪碰撞 | 不能据此认定模型成功或失败；首先需要原始碰撞标签，低速 Autoware 与高速 highD 应分域 |
| 部分故障只有声明 | 模板接受感知丢失、延迟、位置偏差和控制延迟，环境原本只执行强制 BV 动作 | 必须让故障真实作用于控制输入，或明确拒绝不支持的类型，不能静默忽略 |
| 随机性和终止条件不完整 | 扰动种子没有覆盖 Python/NumPy/SUMO；SUMO 使用 `--random`；模板时长未用于终止 | 同一实验难以复现 |
| 启发式风险数值冒充概率 | TTC/距离公式写入 `ndd_step_info` 和训练权重，并相乘为联合权重 | 不能用于无偏重要性采样，必须分离风险代理与真实似然比 |
| 多车训练接口名实不符 | 10 维单车观测取 `per_agent[0]`，同时读取联合权重 | 不是完整 MultiBV 学习；在正确联合策略推导前应拒绝混用 |
| 评测有筛选偏差 | 安全日志可能按风险阈值丢弃；评分偏好默认 1.4 秒和指定碰撞对象 | 需要全体尝试数、失败原因和对真实轨迹的误差，而非追逐手写碰撞目标 |
| 缺少基线与泛化证据 | 当前主要是均匀参数扰动，无统一真轨迹回放/优化对比 | 不能仅靠增加 diffusion、LLM 或轨迹平滑主张创新 |

## 2. 同领域工作与差距

以下工作只能在同数据、同任务、同规划器和同预算下做数值比较；论文中的碰撞率不可直接横向排名。2026 年预印本不是已完成同行评审的结论。

| 工作 | 已覆盖的能力 | 本项目应学习或避开的重复点 |
| --- | --- | --- |
| [D2RL，Nature 2023](https://pubmed.ncbi.nlm.nih.gov/36949337/) | 加速安全测试与统计权重 | 继承代码不等于继承无偏保证；自定义干预必须有合法的采样概率模型 |
| [STRIVE，CVPR 2022](https://research.nvidia.com/labs/toronto-ai/STRIVE/) | 学习交通先验，在潜空间优化多车对抗场景并检查可解性 | 单纯潜变量优化、追求碰撞不新颖；需要合理性和可避免性 |
| [CTG](https://aiasd.github.io/ctg.github.io/) / [CTG++，CoRL 2023](https://proceedings.mlr.press/v229/zhong23a.html) | 可控扩散、动力学约束，语言引导场景生成 | 换成 diffusion 或 LLM 引导不够，需要证据约束和有价值的实验问题 |
| [ChatScene，CVPR 2024](https://openaccess.thecvf.com/content/CVPR2024/html/Zhang_ChatScene_Knowledge-Enabled_Safety-Critical_Scenario_Generation_for_Autonomous_Vehicles_CVPR_2024_paper.html) | 知识辅助的语言场景生成和下游训练 | 本项目须比“文本转模板”多出可量化的轨迹证据和验证闭环 |
| [SoVAR，2024 预印本](https://arxiv.org/abs/2409.08081) | 从事故叙述提取约束并生成轨迹/场景 | “事故描述转可执行场景”已有工作，不能作为独占创新 |
| [SAFE-SIM，ECCV 2024](https://arxiv.org/abs/2401.00391) | 可控扩散对抗生成、闭环交互与合理性评价 | 要评测闭环响应、行为真实性及不同规划器，不仅报告碰撞率 |
| [CCDiff，CVPR 2025](https://arxiv.org/abs/2412.17920) | 因果组合与闭环交通扩散 | 多车交互图或“因果”命名本身不新；因果结论需要明确干预语义 |
| [Adv-BMT，NeurIPS 2025](https://metadriverse.github.io/adv-bmt/) | 从危险终态反向生成交通轨迹 | 从碰撞终点向前倒推不是空白方向 |
| [ScenGE，AAAI 2026](https://github.com/JoFrc/ScenGE) | 知识落地、协作车辆图与轨迹优化 | 图结构加 LLM 加优化已有相近路线 |
| [RiskFlow，2026-06 预印本](https://arxiv.org/abs/2606.06423) | 动作空间 MeanFlow 和风险引导 | 一次生成前向之后仍有引导优化，不能把整个方法称为纯一步；优先考虑动作空间物理约束 |
| [TrafficDiffuser，2026-08](https://arxiv.org/abs/2608.11407) | 起终态约束、多车扩散及轨迹补全 | 轨迹缺失补全本身不是创新，需定义有证据支持的风险边界问题 |
| [COSTER，2026-09 预印本](https://arxiv.org/abs/2609.06433) | 碰撞快照引导与时间反向生成 | 进一步说明“碰撞终态倒推”路线已拥挤 |

## 3. 建议的轨迹生成方案

先做可解释、可验证的基线，再决定是否训练生成模型。

**第一层：证据一致的重建。** 从 highD 的实测车辆轨迹建立独立变道窗口，保留车辆尺寸、采样率、车道线、原记录/车辆/帧 ID。统一为沿行驶方向的局部坐标。按 recording 划分训练/验证/测试，禁止同一记录及其扰动跨集合。完整轨迹作为回放参考；人为遮挡片段作为重建测试。highD 的自然变道不是事故真值。

**第二层：受限局部变化。** 只在允许改变的时间段/车辆上，使用平滑低维基函数或控制序列参数化，约束速度、加速度、jerk、车道边界、起始证据及扰动大小。比较均匀扰动、真实轨迹回放、受约束优化。被测试 CAV 必须能响应，不能把两辆车都回放再称为闭环对抗测试。

**第三层：待验证的研究假设。** 对缺失观测保留多种物理可行补全，比较它们的最小风险诱发扰动。核心问题是：单条重建是否低估/高估风险，以及多解是否给出更可靠的风险边界区间？这只是可实验的方向，不保证“别人没做过”。需要进一步系统查新，且有限候选中找到的最小值不是全局最小解。

若简单优化已有效，再考虑条件 diffusion/flow：输入为观测、缺失 mask、道路和多车状态；输出可积分的加速度/横摆控制；固定观测区域、只生成未知段。8 GB 显存优先做 2–4 车、小模型或冻结预训练先验。模型大小、方法名称不是论文贡献。

## 4. 按顺序实施

| 阶段 | 本轮优先落地内容 | 验收标准 |
| --- | --- | --- |
| P0 文档 | 本路线图、限制和实测记录 | 清楚区分完成/待验证，不承诺新颖性 |
| P1 真轨迹基准 | highD 本地导出、中心坐标、统一时间、记录级 split、源文件哈希 | 完整窗口、禁止泄漏、合成单测和本地真实数据运行；原始及派生轨迹不上传 |
| P2 可信运行 | 固定种子、模板时长、全量结果；故障可执行性检查；去除伪概率、拒绝伪 MultiBV | 相同种子复跑一致，安全/失败运行计入分母，错误不再静默通过 |
| P3 三类基线 | 回放、均匀局部扰动、约束优化；共同评测接口 | 同场景/种子/预算，报告重建误差、物理约束、风险、扰动幅度、耗时 |
| P4 缺失轨迹原型 | 线性/平滑补全对比；检验多解研究是否值得继续 | 隐藏真值不进入生成，评测仅在缺失段；报告失败和适用范围 |
| P5 论文实验（后续） | 更多独立记录与地点、多个规划器、置信区间、消融、下游训练 | 不把小样本工程 pilot 当成论文主结果；验证集调参后冻结测试配置 |

P2 的感知/控制故障若没有可靠的接口实现，先显式拒绝执行、移出可运行示例，再单独实现并验证。不能为了赶进度做“假注入”。完整 Autoware 坐标/时间/目标关联、多智能体重要性采样、生成模型训练和论文级规模实验不属于已完成能力。

## 5. 论文至少应有的实验

- 重建：缺失段 ADE/FDE、观测残差、速度/加速度误差；缺失比例和噪声强度分组。
- 物理合理性：道路越界、速度/加速度/jerk 违反率、初始重叠率；阈值、单位与差分方法明确。
- 反事实：风险成功率、最小间距/TTC、干预车数、偏移幅度、动作代价及计算预算。TTC 必须有几何/同车道条件。
- 闭环：不同规划器的碰撞、完成率、舒适性和是否存在可避免方案；背景回放不是交互行为模型。
- 不确定性：覆盖率、区间宽度、模式覆盖；不能用更宽区间白拿覆盖提升。
- 泛化与统计：按原始 recording 聚合，报告独立场景数、全部尝试数、失败数、多随机种子及置信区间；小样本不报虚假的显著性。
- 消融：移除证据约束、物理约束、最小干预项、多解建模分别造成什么变化。

## 6. 数据与协作

[highD 官方数据说明](https://levelxdata.com/highd-dataset/)：在本地使用获许可数据；不向仓库上传原始或可还原轨迹，提交导出代码、配置、哈希和汇总结果。Autoware 原始 bag、模型权重、日志也不进入普通 Git。

在 `feature/evidence-grounded-benchmark` 上分阶段提交，运行测试后推送并创建 PR，由另一位研究者审查合并。不得直接推 `main`，不得宣称尚未完成的实验已经通过。
