# SHRP2 公共数据碰撞种子处理

## 结论

当前管线可以从 SHRP2 NDS 公共鸟瞰轨迹数据中筛选真实事故事件，生成可复现、可审计的多类型运动学碰撞种子。本次试验生成 12 个场景，覆盖追尾、侧向擦碰、交叉冲突和对向转弯冲突；12 个场景均由非碰撞初态演化到碰撞。

这些产物尚不是 SUMO 闭环事故复现，也不能用于估计真实碰撞率。它们适合作为后续 SUMO 场景构建、碰撞可达性测试和强化学习压力测试的初始条件。

## 数据与版本

- 数据集：SHRP2 NDS Public Bird's-Eye View Trajectory Reconstruction
- DOI：`10.15787/VTT1/T7UUC1`
- 版本：2.0
- 许可：CC BY 4.0
- 原始文件校验：`configs/shrp2_public_checksums.json`
- 原始数据位置：仓库外部目录，不进入 Git

本地解压后的入口必须包含：

```text
Export_Online/
└── SafetyCriticalTestSet/
    └── Crash/
        ├── event_meta.csv
        └── event_data.h5
```

## 处理原则

1. 目标车辆的 `x_sur/y_sur` 表示前保险杠位置，导入时沿目标车辆航向减去半个车长，转换为车辆中心。
2. 公共文件没有明确给出事故主要冲突车辆对应的 `target_id`。管线在标注碰撞时刻附近计算有向包围盒间距，并选择距离最小的目标；这是几何关联假设。
3. 事件采用固定随机种子 `20260914` 按 `event_id` 哈希划分为 70% 训练、15% 验证和 15% 测试。当前只使用训练划分，测试集默认锁定。
4. 公共文件中没有可用于该流程的驾驶人分组键，因此这里只能保证事件互斥，不能声称驾驶人互斥。
5. 每个冲突类型选择所需几何修正量最小的源事件，再生成原速度、自车速度增加 10%、目标车速度降低 10% 三个变体。
6. 仿真使用恒航向、恒速度运动学，并用有向车辆包围盒和每采样间隔 10 个子步核验碰撞。
7. 轨迹在首次接触后仅为数学延拓，不代表车辆碰撞动力学；使用时应在首次碰撞处终止。

## 运行方法

在 `scenario_reconstruction` 仓库根目录执行：

```powershell
python -m scenario_reconstruction.shrp2_collision `
  --source_root 'G:\path\to\SHRP2_Public' `
  --config configs/shrp2_collision_pilot.json `
  --output data_analysis/raw_data/shrp2_collision_pilot
```

输出目录必须为空或不存在。完整逐帧轨迹写入被 Git 忽略的 `data_analysis/raw_data/`，Git 中只保留配置、代码、校验信息和精简结果。

## 本次结果

| 类型 | 源事件 | 关联目标 | 碰撞时几何修正量 | 可信度 |
|---|---:|---:|---:|---|
| 追尾 | 131785457 | 22038 | 0.737 m | 高 |
| 侧向擦碰 | 151856529 | 26006 | 5.187 m | 低 |
| 交叉冲突 | 35258186 | 17272 | 2.946 m | 中 |
| 对向转弯 | 33575100 | 16979 | 2.210 m | 中 |

可信度规则是：修正量不大于 1 m 为高，不大于 3 m 为中，其余为低。每个源事件生成 3 个速度变体，因此高、中、低可信场景数分别为 3、6、3。

- 生成场景：12
- 核验发生碰撞：12
- 初始时刻已经碰撞：0
- 首次接触相对设定碰撞时刻误差：-0.02 至 0.00 s
- 两次独立输出的汇总结果完全一致

机器可读结果见 `results/shrp2_collision_pilot_summary.json`。

## 不能据此声称的内容

- 不能把经过位置条件化的种子描述为 SHRP2 事故的精确重放。
- 不能把运动学包围盒相交描述为 SUMO 或真实车辆闭环碰撞。
- 不能使用碰撞后的恒速轨迹分析冲击过程、伤害或车辆动力学。
- 不能从当前样本推断自然驾驶分布概率、D2RL 重要性权重或真实事故率。
- 侧向擦碰的几何修正超过 5 m，应单独标为低可信压力测试，不进入主要有效性结论。

## 下一步

1. 为追尾/擦碰建立直路多车 SUMO 模板，为交叉冲突建立交叉口模板，为对向转弯建立双向交叉口模板。
2. 将高、中可信种子的首次接触前状态映射到对应道路坐标，并在 SUMO 中重新核验初始无重叠、碰撞时间和碰撞类型。
3. 在首次接触时终止回合，保存 SUMO 碰撞日志、最小间距、TTC、PET 和动作序列。
4. 在训练/验证划分上冻结筛选阈值和场景生成器后，才允许用 `--allow_test` 运行一次测试划分。
5. 若用于 D2RL 训练，需要另外定义自然驾驶行为概率 `p(x)`、加速分布 `q(x)` 和似然比；SHRP2 碰撞种子本身不能替代这些概率。
