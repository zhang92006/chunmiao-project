# 真实轨迹基准与筛选实验

这是论文实验的基础设施和小样本 pilot，不是一个已经达到发表效果的生成模型。

## 本地数据准备

使用本人获许可的 highD v1.0 数据目录，包含 `01_tracks.csv` 等文件。不要把数据或导出的逐帧轨迹加入 Git。下列 `<HIGH_D_DATA>` 替换为本地数据目录，命令从本仓库根目录执行：

```bash
python -m scenario_reconstruction.highd --data_dir "<HIGH_D_DATA>" --config configs/highd_pilot.json --output data/processed/highd_pilot_v2
python -m scenario_reconstruction.trajectory_benchmark --manifest data/processed/highd_pilot_v2/manifest.json --config configs/trajectory_baselines.json --split validation --output data_analysis/raw_data/trajectory_pilot_v3
```

若输出目录已有内容，请使用新的运行目录。程序不会清空旧实验，也不会把旧文件混入新结果。

导出器按原始 `recording` 划分：01/02 为训练，03 为验证，04 为测试；各选最多 12 个完整变道窗口，每个变道车辆最多取一个事件。窗口为变道前后各 2 秒，默认保留原始 25 Hz，最多 4 辆车。CAV 是新车道上的后车，变道车辆是 BV；没有完整目标后车的片段明确拒绝。

默认还要求 CAV 在整个窗口内保持车道，便于解释固定车道 IDM 对比（`require_lane_stable_cav=true`）。其他 BV 可以变道；后续多车横向交互实验应另设配置和评测协议。

highD 的 `x/y` 是框的左上角，`width` 是纵向车长，`height` 是横向车宽。输出使用车辆中心，x 向前、y 向左；CAV 在窗口开始时位于局部原点。使用实际车道线、尺寸和时间戳，保存原始车辆/帧 ID、输入 CSV 哈希及场景文件哈希。缺失数据不被偷偷填充到真值中。

同一 recording 内的窗口仍可能相关，甚至共享其他车辆，不能把它们当成独立录像。当前验证结果仅来自 1 个 recording；跨记录划分也不等于跨地点泛化。

## 三类反事实筛选基线

三类基线均以完整真轨迹为参考，因此是 **回放条件下的反事实筛选，不是未来轨迹预测**：

| 方法 | 行为 | 预算 |
| --- | --- | --- |
| replay | BV 沿实测轨迹回放 | 每场景 1 次，无搜索 |
| uniform | 在相同二维有界空间均匀采样变道车的纵/横向偏移 | 每场景最多 24 次，包含零扰动 |
| constrained_search | 坐标方向模式搜索；仅从通过物理筛选的候选中选择 | 相同最多 24 次，实际次数记录在结果中 |

这里的 uniform 是与约束搜索共用参数空间的局部轨迹基线，不是对旧版“初始位置/速度/事件时间扰动”的逐项复刻；旧版仍可由 `run_batch` 运行。

使用五次 smoothstep 将偏移接入未来段，固定前 1 秒的位置、速度和加速度。只有变道 BV 被干预，其他 BV 回放；CAV 在前 1 秒遵循观测，之后使用固定车道的纵向 IDM 响应。不是把 CAV 也全程回放来制造碰撞，但背景车仍不响应 CAV。

物理筛选包括速度、纵/横向加速度、jerk、道路外边界、初始框重叠、BV–BV 碰撞。车辆尺寸来自数据。原始速度/加速度采用 highD 提供的滤波值，扰动采用解析导数；另外报告位置差分与原始速度的残差。它们并非严格完全一致，筛选通过不等于已证明自行车模型动力学可行。

碰撞和间距采用采样时刻的轴对齐车框；TTC 仅计算横向重叠、前方有正间距且正在接近的情况，无定义时为 `null`。尚未使用旋转车框、连续碰撞检测、轮胎模型、MOBIL 横向避让或真实感知延迟。CAV 的 jerk 是整个固定时域诊断，包括可能的碰撞后延续，不是完整规划器舒适性结论。

目标优先选择可行碰撞候选中的较小扰动；若没有碰撞，则最小化间距加扰动惩罚。这只是有限候选/局部搜索的结果，不是全局最小风险干预。零扰动可以胜出，不会为了制造碰撞放宽约束。

## 缺失段重建与不确定性诊断

另一个独立实验隐藏变道车约 1.25–2.75 秒的位置。生成函数只接收含 `NaN` 的观测数组，不接收隐藏真值；线性插值、自然三次样条和 PCHIP 分别补全，误差只在隐藏段计算，所有已观测位置严格保留。窗口两端必须可见，不支持外推。

补全后的高斯平滑扰动包络只用于调试覆盖率与宽度接口：它是手选尺度，没有学习、校准或物理筛选，不能称为后验、置信区间或新方法。当前并未把补全不确定性传播到“最小风险干预”的分布；那是下一阶段的研究工作。
